### 1.新增功能

#### 1.1 新增`购纸明细查询`页面

_此页面用于查询购纸明细，方便用户了解购纸情况。_

此页面的地址为`A07`，对应的路由配置如下：

```json
{
  "meta": {
    "title": "购纸明细查询"
  },
  "name": "购纸明细查询",

  "path": "A07",
  "component": "pdA07"
},
```

## ver 0.5.0

**更新日期**:`2026-03-31`

### 1. 数据库字段新增

#### 1.1 `book-catalogue` 图书信息表新增字段

| 字段名  | 数据类型     | 可为空 | 示例                              | 备注                                   |
| ------- | ------------ | ------ | --------------------------------- | -------------------------------------- |
| o_items | varchar(512) | T      | `fm&sgy&zw&jc`                    | 图书详细项目，多个用&分隔              |
| o_size  | varchar(512) | T      | `210*297mm&—&210*297mm&195*285mm` | 图书尺寸，多个用&分隔，遇非尺寸用—代替 |
| o_color | varchar(512) | T      | `4+0&—&2+2黑+兰&2+2黑+兰`         | 图书颜色，多个用&分隔                  |
| o_craft | varchar(512) | T      | `—&—&胶订&骑订`                   | 图书工艺，多个用&分隔                  |
| o_yz    | varchar(512) | T      | `0.25&—&6.5&3`                    | 图书印张，多个用&分隔                  |

#### 1.2 `other-info` 其他信息表新增数据

新增 `id` 为 `now_season` 的数据, `nameID` 为 `now_season_name`, `main` 为 `[{"year1": "20", "year2": "26", "season1": "C", "season2": "春" }]`

#### 1.3 `pflist` 印厂信息表新增字段

| 字段名    | 数据类型    | 可为空 | 示例       | 备注             |
| --------- | ----------- | ------ | ---------- | ---------------- |
| shortName | varchar(64) | T      | `长春新华` | 供印刷信息表使用 |

#### 1.4 `routes` 路由表字段更新

- 新增新式付印单详情页面
- 新增`签收未印刷样书`页面

```json
{
  "name": "付印单详情（隐）",
  "path": "new-fyd-v2",
  "hidden": true,
  "component": "newFYDv2"
},
{
  "meta": {
    "title": "签收未印刷样书"
  },
  "name": "签收未印刷样书",
  "path": "sing-samplebook-2",
  "children": [
      {
        "name": "查询【B】",
        "path": "test1",
        "hidden": true,
        "component": "sss"
      }
  ],
  "component": "SingSamplebook2"
}
```

#### 1.5 `pfat` 印厂往来账字段类型修改

- receipt 字段类型由 `tinyint(1)` 改为 `varchar(512)`, 方便后续对接

### 2. 功能新增及优化

#### 2.1 新增图书信息集合功能

- 新增图书信息集合功能，方便制作付印单一键带入项目信息
- 图书信息上传功能新增集合信息

#### 2.2 功能优化

- 优化 API `otherInfo` 调用，新增 `store.js` 中 `nowSeason` 字段，方便前端调用
- 优化当季信息获取逻辑，由之前的 `不变参数` 改为直接从数据库中查询，节省因参数变动而重新编译部署的问题
- 优化印厂名称因 `status = 0` 导致查询表无法正常显示名称的问题
- 新增样书单据详情页面调整字段顺序
- 优化 印厂对账页面 `radio=3` 时返回数据的 API 接口
- API 部分接口新增 `nowSeason` 字段，方便前端调用

#### 2.3 重构付印单新增页面

- 重新设计 MD5 字段，利用新算法生成，防止重复录入
- 利用 `1.1 book-catalogue 图书信息表新增字段` 方便一键带入项目信息
- 各计算方法单独封装，方便后续扩展

#### 2.4 登录页面优化

- 新增 Bing 每日壁纸背景，美化登录页面

#### 2.5 印厂往来账新增全部导出功能

- 为了需求，新增全部导出功能
